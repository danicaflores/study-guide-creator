# STAT 2011 — Lecture 8: z-scores and the Normal Distribution
Exam 2 objectives:
1. Compute and interpret a z-score.
2. Use the empirical rule (68-95-99.7).
3. Find probabilities using the standard normal table.
4. Distinguish population vs sample standard deviation.

Notes:
- z = (x - μ) / σ  → number of standard deviations x is from the mean.
- Positive z = above mean, negative z = below mean.
- Empirical rule: for a normal distribution about 68% of data within 1σ, 95% within 2σ, 99.7% within 3σ.
- Sample std dev: s = sqrt( Σ(x - x̄)² / (n - 1) ). Population: σ = sqrt( Σ(x - μ)² / N ).
- Prof: "Don't forget n − 1 for samples! Most common mistake on last year's exam."
- Example from class: Exam scores μ = 72, σ = 8. A score of 88 → z = (88-72)/8 = 2.0.
- Standard normal table gives area to the LEFT of z. P(Z < 1.00) = 0.8413.
